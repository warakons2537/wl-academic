# คู่มือติดตั้ง WL Academic

WL Academic ใช้ **Supabase project เดียวกับ WL Admin** และบัญชีผู้ใช้ชุดเดียวกัน
ติดตั้งครั้งแรกใช้เวลาประมาณ 15 นาที ทำ 3 ขั้นตอน

---

## ขั้นที่ 1 — เพิ่มตารางของ WL Academic ใน Supabase (ครั้งเดียว)

1. เปิด [supabase.com](https://supabase.com) → เลือกโปรเจกต์เดียวกับ WL Admin
2. เมนูซ้าย **SQL Editor** → **New query**
3. เปิดไฟล์ `supabase/academic.sql` คัดลอก **ทั้งไฟล์** มาวาง → กด **Run**
4. ขึ้น `Success. No rows returned` = เรียบร้อย

> ไฟล์นี้ **ไม่แก้ตารางเดิมของ WL Admin** สร้างเฉพาะตารางใหม่ และรันซ้ำได้โดยข้อมูลไม่หาย
> ถ้าขึ้นข้อความ "ยังไม่พบฐานข้อมูลของ WL Admin" แปลว่าเลือกโปรเจกต์ผิด

ตารางที่สร้าง: `staff` (บุคลากร — ตารางกลางของทุกแอปในเครือ WL), `ac_settings`, `ac_assets`, `ac_tasks`, `ac_assignments`, `ac_orders`

---

## ขั้นที่ 2 — สร้าง repo และเปิดเว็บด้วย GitHub Pages

1. GitHub → ปุ่ม **New** (สร้าง repository ใหม่)
   - Repository name: **`wl-academic`**
   - เลือก **Public** (โค้ดเปิดเผยได้ ข้อมูลจริงอยู่ใน Supabase ซึ่งคุมสิทธิ์ด้วย RLS)
   - กด **Create repository**
2. หน้า repo ที่ว่างอยู่ → ลิงก์ **uploading an existing file**
3. แตกไฟล์ ZIP ที่ได้รับ แล้วลาก **ทุกไฟล์และโฟลเดอร์ข้างใน** (`index.html`, `js`, `css`, `img`, `supabase`, `docs`, …) ไปวาง → **Commit changes**
4. **Settings** → **Pages** → Source: **Deploy from a branch** → Branch: **main** / **(root)** → **Save**
5. รอ 1–2 นาที เว็บจะอยู่ที่
   **`https://warakons2537.github.io/wl-academic/`**

> `js/config.js` ใส่ค่าการเชื่อมต่อของโปรเจกต์ Supabase เดียวกับ WL Admin ไว้ให้แล้ว (Publishable key เปิดเผยในหน้าเว็บได้ตามปกติ)
> ถ้าเปลี่ยนโปรเจกต์ Supabase ภายหลัง ให้แก้ไฟล์นี้ไฟล์เดียว

---

## ขั้นที่ 3 — เข้าใช้งานครั้งแรก

1. เปิด `https://warakons2537.github.io/wl-academic/`
   - ถ้าเข้า WL Admin ค้างไว้ในเบราว์เซอร์เดียวกัน จะเข้าได้ทันทีโดยไม่ต้องล็อกอิน
   - ถ้ายังไม่ได้เข้า ใช้อีเมลและรหัสผ่านเดียวกับ WL Admin
2. ทำตาม **ขั้นตอนตั้งต้น** ในหน้าแรก:
   1. ข้อมูลโรงเรียนและผู้อำนวยการ (ใช้ร่วมกับ WL Admin)
   2. อัปโหลดตราครุฑ (PNG พื้นโปร่งใส)
   3. รายชื่อบุคลากร — ใช้ปุ่ม **วางรายชื่อจาก Excel** หรือ **นำเข้าจากผู้ใช้ WL Admin** จะเร็วที่สุด
   4. คลังงานวิชาการ — เลือก **ชุดทางการ** หรือ **ชุดปรับใช้จริง**
   5. จัดภาระงาน — คลิกช่องในตาราง: ว่าง → ห → ก → ล
   6. ออกคำสั่ง → พิมพ์ / PDF หรือดาวน์โหลด Word

### ใครเข้าได้บ้าง

| ผู้ใช้ (ตามบทบาทใน WL Admin) | ตอนเริ่ม | เมื่อเปิดสวิตช์ "ให้ครูทุกคนเข้าดู" |
|---|---|---|
| ผู้ดูแล (admin) | ใช้ได้ทุกอย่าง | ใช้ได้ทุกอย่าง |
| ครู (teacher) | เห็นข้อความ "ยังไม่เปิดให้ครูใช้งาน" | ดูได้อย่างเดียว |
| รออนุมัติ (pending) | เข้าไม่ได้ | เข้าไม่ได้ |

สวิตช์อยู่ที่ **ข้อมูลพื้นฐาน › ตั้งค่าแอป** สิทธิ์ถูกบังคับในฐานข้อมูล (RLS) ไม่ใช่แค่ซ่อนปุ่ม

## การอัปเดตครั้งต่อไป

1. ได้ไฟล์ ZIP ใหม่ → อัปโหลดไฟล์ทับใน GitHub (**ยกเว้น `js/config.js`** ถ้าเคยแก้ไว้)
2. ถ้า `supabase/academic.sql` เปลี่ยน → รันใหม่ใน SQL Editor (รันซ้ำได้)
3. เปิดเว็บแล้วกด **Ctrl+F5** (Mac: **Cmd+Shift+R**) เพื่อโหลดไฟล์ใหม่

## ติดตั้งเป็นแอปบน iPad / Mac / iPhone

- **iPad / iPhone (Safari):** ปุ่มแชร์ → **เพิ่มไปยังหน้าจอโฮม**
- **Mac (Chrome / Edge):** แถบที่อยู่ → ไอคอน **ติดตั้ง** · **Safari:** เมนู ไฟล์ → **เพิ่มไปยัง Dock**
