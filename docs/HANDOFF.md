# WL Academic — สรุปโครงการสำหรับคุยต่อในแชทใหม่

> วิธีใช้: เริ่มแชทใหม่ แนบ ZIP ของโค้ด (หรือบอกชื่อ repo `warakons2537/wl-academic`) และไฟล์นี้ แล้วบอกว่า
> "นี่คือ WL Academic ที่ทำต่อจากแชทก่อน อ่าน docs/HANDOFF.md ก่อน แล้วช่วย…"
> อัปเดตล่าสุด: 23 ต.ค. 2569 (เฟส 0–2 เสร็จ)

## 1. แอปนี้คืออะไร

**WL Academic** — จัดการงานวิชาการ โรงเรียนบ้านวังลึก (ยุวนาฏชนูทิศ) แอปในเครือ "Wangluek(Y.N.) Connected"
ร่วมกับ WL Admin (ธุรการชั้นเรียน & ปพ., repo `warakons2537/pp`), WL Scheduler และระบบสอนแทน

- หน้าเว็บ HTML/JS ล้วน ไม่มี build · GitHub Pages `https://warakons2537.github.io/wl-academic/`
- ฐานข้อมูล **Supabase project เดียวกับ WL Admin** — บัญชีผู้ใช้ `profiles` / `school_settings` / `terms` ใช้ร่วมกัน
- อยู่ origin เดียวกับ WL Admin (`warakons2537.github.io`) → ล็อกอินที่แอปหนึ่ง อีกแอปเข้าได้ทันที
- `js/config.js` ว่าง = โหมดทดลอง (ข้อมูลตัวอย่างใน localStorage) ใช้ทดสอบหน้าจอ
- ธีมม่วง-ทองตามโลโก้ (`img/`, `js/brand.js`) โครงหน้าแบบเดียวกับ WL Admin

## 2. สิ่งที่ตกลงกันไว้

- ตอนเริ่ม: เฉพาะผู้ดูแล (role `admin` ของ WL Admin = ฝ่ายวิชาการ) · ครูเปิดภายหลังด้วยสวิตช์ `ac_settings.teachers_enabled` — ครูดูได้ทุกหน้า และส่งเอกสารของตัวเองได้ (ทริกเกอร์ `ac_guard_submission` บังคับสถานะ "รอตรวจ" และกันแก้ความเห็นผู้ตรวจ)
- **ตาราง `staff` เป็นรายชื่อบุคลากรกลางของทุกแอปในเครือ WL** มีชื่อได้แม้ไม่มีบัญชี ผูกบัญชีที่ `profile_id`
- คลังงานวิชาการมี 2 ชุด: ทางการ (17 งานตามกฎกระทรวงกระจายอำนาจ พ.ศ. 2550) และปรับใช้จริง (17 งาน 6 กลุ่ม รวมทะเบียน/ทดสอบระดับชาติ/แข่งขันทักษะ) — `js/task-sets.js`
- ข้อมูลรายปีการศึกษา (`ac_tasks.academic_year`) · คัดลอกจากปีก่อนได้ (`ac_copy_year`)
- คำสั่ง: แก้ไขได้ขณะเป็นฉบับร่าง · "ออกคำสั่ง" = ล็อกและเก็บ snapshot รายชื่อ ณ วันนั้น
- ไม่แก้ตารางเดิมของ WL Admin เลย (ยกเว้นแก้ค่าใน `school_settings` ผ่านหน้าจอ ซึ่งใช้ร่วมกันโดยตั้งใจ)
- repo Public มีแต่โค้ด ข้อมูลจริงอยู่ใน Supabase · ห้ามใส่ Secret key

## 4. รายละเอียดเอกสารคำสั่ง

- แบบจำลองเดียว (`js/order-doc.js` buildModel) → ใช้ทั้งหน้า A4 บนจอ (`renderPages`) และ Word (`js/docx.js`)
- A4 ขอบ บน 2.5 ล่าง 2 ซ้าย 3 ขวา 2 ซม. · ครุฑสูง 3 ซม. · ย่อหน้า 2.5 ซม. · TH SarabunPSK 16pt (บรรทัด 20pt)
- ไม่มีฟอนต์ในเครื่อง → ใช้ Sarabun 11.85pt (≈ 74% ตามที่ WL Admin หาไว้)
- แบ่งหน้าด้วยการวัดความสูงบล็อก (`paginate`) หัวข้อ/“มีหน้าที่”/ย่อหน้า "ทั้งนี้" ติดกับบล็อกถัดไป · เลขหน้า "- ๒ -" ตั้งแต่หน้า 2
- Word: รายชื่อเป็นตารางไม่มีเส้น (ชื่อยาวขึ้นบรรทัดในช่อง) · ย่อหน้า Thai Distributed · เลขหน้า `pgNumType thaiNumbers` + `titlePg`
- ทดสอบด้วย LibreOffice (ไม่มีฟอนต์ PSK ในเครื่องทดสอบ) — **ยังไม่ได้ตรวจใน Microsoft Word จริง**

## 7. วิธีทดสอบ

- `node tests/order.test.mjs` — ตัวเลขไทย, ชุดงาน, ภาระงาน, แบบจำลองคำสั่ง, แบ่งหน้า, .docx
